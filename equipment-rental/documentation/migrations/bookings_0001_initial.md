## Мета

Створити таблиці бронювань і журналу подій та базові обмеження цілісності.
Заборону перетину періодів винесено в окрему міграцію 0003, бо їй потрібне
розширення PostgreSQL (міграція 0002).

## Зміни в схемі

### `bookings_booking`

| Поле | Тип у БД |
|---|---|
| `unit_id` | `bigint`, FK → `catalog_equipmentunit` |
| `client_id` | `bigint`, FK → `accounts_user` |
| `start_date`, `end_date` | `date` |
| `status` | `varchar(16)` |
| `price_per_day` | `numeric(10,2)` |
| `total_price` | `numeric(12,2)` |
| `created_at`, `updated_at` | `timestamp with time zone` |

Обмеження та індекси:

| Назва | Вид | Умова |
|---|---|---|
| `booking_end_after_start` | CHECK | `end_date > start_date` |
| `booking_total_non_negative` | CHECK | `total_price >= 0` |
| `booking_client_status_idx` | індекс | (`client_id`, `status`) — для сторінки «Мої бронювання» |

### `bookings_bookingevent`

`booking_id` (FK), `kind`, `actor_id` (FK → користувач), `comment`, `created_at`.

## SQL (скорочено)

```sql
CREATE TABLE "bookings_booking" (
  "id" bigint NOT NULL PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  "start_date" date NOT NULL,
  "end_date" date NOT NULL,
  "status" varchar(16) NOT NULL,
  "price_per_day" numeric(10, 2) NOT NULL,
  "total_price" numeric(12, 2) NOT NULL,
  "created_at" timestamp with time zone NOT NULL,
  "updated_at" timestamp with time zone NOT NULL,
  "client_id" bigint NOT NULL,
  "unit_id" bigint NOT NULL
);
CREATE TABLE "bookings_bookingevent" (...);
CREATE INDEX "booking_client_status_idx" ON "bookings_booking" ("client_id", "status");
ALTER TABLE "bookings_booking" ADD CONSTRAINT "booking_end_after_start" CHECK ("end_date" > ("start_date"));
ALTER TABLE "bookings_booking" ADD CONSTRAINT "booking_total_non_negative" CHECK ("total_price" >= 0);
-- + зовнішні ключі та індекси на них
```
