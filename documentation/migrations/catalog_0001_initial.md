## Мета

Створити структуру каталогу: що можна орендувати (тип), конкретні предмети
(екземпляри) та їхні ціни з історією (тарифи).

## Зміни в схемі

| Таблиця | Поля | Обмеження |
|---|---|---|
| `catalog_equipmenttype` | `name`, `category`, `description`, `is_active` | `name` UNIQUE |
| `catalog_equipmentunit` | `equipment_type_id`, `inventory_number`, `status`, `note` | `inventory_number` UNIQUE; FK на тип |
| `catalog_tariff` | `equipment_type_id`, `price_per_day numeric(10,2)`, `valid_from date` | `tariff_unique_per_type_and_date` UNIQUE (`equipment_type_id`, `valid_from`); `tariff_price_positive` CHECK (`price_per_day > 0`); FK на тип |

Індекси на зовнішні ключі та `*_like`-індекси для пошуку за префіксом
Django створює автоматично.

## SQL (скорочено)

```sql
CREATE TABLE "catalog_equipmenttype" (
  "id" bigint NOT NULL PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  "name" varchar(200) NOT NULL UNIQUE,
  "category" varchar(100) NOT NULL,
  "description" text NOT NULL,
  "is_active" boolean NOT NULL
);
CREATE TABLE "catalog_equipmentunit" (
  "id" bigint NOT NULL PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  "inventory_number" varchar(50) NOT NULL UNIQUE,
  "status" varchar(16) NOT NULL,
  "note" varchar(255) NOT NULL,
  "equipment_type_id" bigint NOT NULL
);
CREATE TABLE "catalog_tariff" (
  "id" bigint NOT NULL PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  "price_per_day" numeric(10, 2) NOT NULL,
  "valid_from" date NOT NULL,
  "equipment_type_id" bigint NOT NULL,
  CONSTRAINT "tariff_unique_per_type_and_date" UNIQUE ("equipment_type_id", "valid_from"),
  CONSTRAINT "tariff_price_positive" CHECK ("price_per_day" > 0)
);
ALTER TABLE "catalog_equipmentunit" ADD CONSTRAINT ... FOREIGN KEY ("equipment_type_id")
  REFERENCES "catalog_equipmenttype" ("id") DEFERRABLE INITIALLY DEFERRED;
ALTER TABLE "catalog_tariff" ADD CONSTRAINT ... FOREIGN KEY ("equipment_type_id")
  REFERENCES "catalog_equipmenttype" ("id") DEFERRABLE INITIALLY DEFERRED;
```

`ON DELETE` у SQL немає, бо поведінку `PROTECT` / `CASCADE` Django реалізує на
рівні застосунку.
