# Огляд проєкту

## Мета

Спростити оренду обладнання (фото- й відеотехніки, світла, туристичного
спорядження, інструментів): клієнт сам бачить, які екземпляри вільні на потрібні
дати, і одразу отримує вартість, а сервіс не допускає подвійного бронювання.

## Ролі

| Роль | Що може |
|---|---|
| Гість | Переглядати каталог, шукати й фільтрувати, бачити зайняті періоди, зареєструватися |
| Клієнт | Усе, що гість + створювати бронювання, переглядати й скасовувати власні |
| Менеджер | Видавати й приймати обладнання, скасовувати бронювання з причиною, керувати каталогом через адмінку |

## Предметні сутності

| Сутність | Модель | Призначення |
|---|---|---|
| Тип обладнання | `catalog.EquipmentType` | Позиція каталогу («Камера Sony A7 III») |
| Екземпляр | `catalog.EquipmentUnit` | Конкретний предмет з інвентарним номером; саме його бронюють |
| Тариф | `catalog.Tariff` | Ціна доби, чинна з певної дати; історія зберігається |
| Бронювання | `bookings.Booking` | Заявка клієнта на екземпляр і період |
| Подія бронювання | `bookings.BookingEvent` | Хто, коли й що зробив із заявкою |

## Основний процес

```
Клієнт: каталог → картка обладнання → вибір екземпляра й дат → заявка
Система: перевіряє заявку → підтверджує (confirmed) або відхиляє з поясненням (не зберігає)
Менеджер: видати (issued) → прийняти (returned)
Клієнт або менеджер (з причиною): скасувати до видачі (cancelled)
```

## Ключові бізнес-правила

1. Активні бронювання (`confirmed`, `issued`) одного екземпляра не перетинаються.
2. Період напіввідкритий: `[дата видачі; дата повернення)`. Після повернення діє технічна перерва (задається для типу обладнання, за замовчуванням 1 день): екземпляр зайнятий до `дата повернення + перерва`.
3. Вартість = кількість діб × ціна тарифу, чинного на дату видачі. Ціна фіксується в заявці.
4. Не можна бронювати на минулу дату, а дата повернення має бути пізніше за дату видачі.
5. Екземпляр на обслуговуванні або списаний не бронюється.
6. Ручного погодження немає: коректна заявка підтверджується автоматично, некоректна не зберігається.
7. Переходи статусів обмежені (див. [modules/bookings.md](modules/bookings.md)); видати можна не раніше дати початку; менеджер скасовує лише з причиною.
